Pemrograman Dasar

Komentar, Variabel, dan Tipe Data

Catatan Pemrograman Dasar Kelas X RPL: cara menulis catatan di dalam kode, menyimpan nilai, dan memilih jenis data yang tepat dalam bahasa C.

1. Komentar

Komentar adalah teks di dalam kode yang diabaikan compiler. Fungsinya murni untuk manusia: menjelaskan alur logika, memudahkan maintenance, dan membantu kolaborasi tim.

JenisSintaksCakupan
Single-line// teksSatu baris
Multi-line/* teks */Satu hingga banyak baris
komentar.c
// Ini adalah komentar single-line
#include <stdio.h>

/*
Komentar multi-line untuk
penjelasan yang lebih panjang.
*/
int main() {
    // Menampilkan teks ke layar
    printf("Hello World");
    return 0;
}

2. Variabel

Variabel adalah tempat penyimpanan data di memori yang diberi nama, dan nilainya bisa dipakai atau diubah selama program berjalan. Bayangkan sebuah kotak berlabel: label adalah nama variabel, isi kotak adalah nilai, dan jenis barang yang boleh masuk adalah tipe data.

#BagianKeterangan
1Nama (identifier)Label untuk memanggil nilai
2Tipe dataJenis nilai yang boleh disimpan
3NilaiData aktual di dalam variabel
variabel.c
int   angka = 10;
float phi = 3.14;
char  nilai = 'A';
char  nama[] = "Farid";

Aturan penamaan

ContohStatusAlasan

Nama variabel bersifat case-sensitive: nama dan Nama adalah dua variabel berbeda.

3. Tipe Data

Tipe data menentukan jenis nilai, ukuran memori, dan operasi yang bisa dilakukan. Tipe primitif di C ada empat, lengkap dengan format specifier untuk printf().

TipeFungsiContohSpecifier
intBilangan bulat1, 2, 3%d / %i
floatDesimal, ±6–7 digit3.14%f
doubleDesimal, ±15 digit1.234567890%lf
charSatu karakter, tanda petik satu'A'%c
char[]String, tanda petik dua"Farid"%s

Bagaimana dengan string?

Bahasa C tidak punya tipe string bawaan. String direpresentasikan sebagai array of char (char[]) dan ditulis dengan tanda petik dua.

4. Escape Sequence

Kombinasi karakter yang diawali backslash (\) untuk karakter khusus yang tidak bisa diketik langsung.

\nPindah ke baris baru
\tTab (indentasi horizontal)
\"Menampilkan tanda kutip dua
\'Menampilkan tanda kutip satu
\\Menampilkan backslash
biodata.c
#include <stdio.h>

int main() {
    char nama[] = "Farid";
    int umur = 20;
    float tinggi = 170.5;

    printf("Nama\t: %s\n", nama);
    printf("Umur\t: %d tahun\n", umur);
    printf("Tinggi\t: %.1f cm\n", tinggi);
    return 0;
}

Perhatian

Tanpa \n, semua hasil printf() tercetak menyambung dalam satu baris. Ini kesalahan yang sering terjadi pada pemula.

5. Rangkuman

  • Komentar (// dan /* */) tidak memengaruhi program, tetapi penting untuk dokumentasi.
  • Variabel terdiri dari nama, tipe data, dan nilai.
  • Tipe primitif: int, float, double, char. String adalah char[].
  • Setiap tipe punya format specifier sendiri pada printf().
